Абуз мини-игры "Атака Автоматонов" Dota2. 
Скрипт спамит перечень букв которые есть в название героев и предметов, со скоростью 10.000 символов в 1 секунду. 
Нагрузки на ЦП нет, так как скрипт не эмулирует нажатие клавиш, он сразу вводит нужные буквы в системе. С игрой никак не взаимодействует, ОЗУ не читает, вероятность блокировки нулевая.
Написан на Python.

Арч-based гайд

1. Зависимости
```
sudo pacman -S --needed python tk
```
2. Отдельная виртулка чтобы не срать
```
mkdir -p dota-spammer
cd dota-spammer
python -m venv .venv
```
самое важное хз, команду ниже нужно выполнять в bash или zsh, fish иди нах ;|
```
bash
source .venv/bin/activate
python -m pip install pynput
```
3. запуск скрипта
Кидаете spammer.py в dota-spammer и запускаете
```
python spammer.py
```
если не ворк то 
```
chmod +X spammer.py
```


Цифра "1" на клавиатуре - запуск скрипта. Цифры "2" - остановка скрипта. linux
для вейленд типочков все норм можете свапать окна оно не включиться само(надеюсь, у меня нет)
